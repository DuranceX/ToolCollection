# Tool Collection

前端小工具集。多页面结构，每个工具独立打包，处理全部在浏览器本地完成。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 构建到 dist/
npm run check    # 类型检查 + 单元测试 + fuzz
```

## 目录结构

```
index.html                    首页入口
tools/<tool>/index.html       各工具入口
src/
  shared/                     跨页面共用：主题、顶栏、设计变量
  landing/                    首页
  json-formatter/             JSON 工具
    lib/                      纯逻辑（可单独测试）
    components/               视图组件
    composables/              状态与持久化
test/                         lib/diff.ts 的测试与 fuzz
```

## 新增一个工具

1. 建 `tools/<name>/index.html`（照抄现有入口，改 title 和 script 路径）
2. 建 `src/<name>/`，写 `main.ts` + `App.vue`
3. `vite.config.ts` 的 `build.rollupOptions.input` 加一行
4. `src/landing/data.ts` 的 `tools` 加一张卡片

首页的「工具列表」和「相关链接」共用 `ItemCard.vue`，加站外链接改 `data.ts` 的 `links` 即可，会自动开新窗口并带外链角标。

主题切换和顶栏直接从 `src/shared/` 引，不用重写。新入口的 HTML 记得照抄那段内联主题脚本，否则刷新会闪一下白底。

主题只有明暗两态：首次打开跟随系统，手动切过之后记住选择、不再被系统改动带走（`localStorage` 里没值 = 跟随系统）。

跨工具复用的东西放 `src/shared/`（主题、顶栏、设计变量、通用格式化函数）。工具之间不要互相 import。

## 已有工具

### JSON 格式化 / 对比

- 格式化、压缩、按键名排序、转义 / 去转义，缩进可选 2 / 4 空格或 Tab
- 编辑器基于 CodeMirror 6：语法高亮、代码折叠、错误波浪线、大文件虚拟滚动
- 语法报错定位到具体行列并给出中文说明，另外会警告重复 key
- 多标签管理多份 JSON，双击标签重命名，状态存 localStorage
- 任选两个标签做**结构化对比**，两种视图可切换：
  - **两列** — 左右并排，行对齐由数据结构决定，附字符级高亮
  - **变更清单** — 按 key 路径列出增 / 删 / 改 / 移动

结构化对比不是按文本行比对，所以 key 顺序调整、数组元素移动不会产生连锁假差异。

快捷键：`Ctrl/Cmd + Enter` 格式化，`Alt + T` 新建标签，`F2` 重命名当前标签。

### 便签集

- 点「新建便签」新增，新卡片出现在最前
- 卡片统一高度，内容超出的截断并渐隐；点卡片打开弹窗编辑
- 编辑器是所见即所得：标题直接显示为大字号、`**粗体**` 直接是粗的、`- [ ]` 是可点的复选框。语法标记平时隐藏，光标移到那一行才显出来
- 支持 Markdown：标题、列表、任务列表、代码块、表格、引用、链接
- 标签分类：一条便签最多 8 个标签，点标签栏筛选，在某个标签下新建会自动带上它
- 置顶、按内容和标签搜索
- 导出 / 导入 JSON，导入默认合并（同 id 覆盖），脏数据逐条修补而非整份丢弃

卡片位置稳定：只有置顶的会浮到前面，编辑不会让卡片跳位置。

标签颜色由系统分配、不让用户挑：新标签取当前用得最少的颜色，分配结果存进数据文件，所以一旦定了就永久稳定，同名标签在任何位置都同色。前 8 个标签必然互不同色。（没用「名字哈希」定色：8 种颜色随机取 6 次期望只有 4.4 种不重复，实测中文标签经常 3~4 个撞成同色，而标签颜色的意义就是区分标签。哈希只作为没有分配记录时的回落。）

所见即所得由 `lib/live-markdown.ts` 实现——遍历 CodeMirror 的 Lezer 语法树打装饰，和 Obsidian 的实时预览同一路子。编辑器约 600 KB，所以按需加载：首屏只用轻量的 markdown-it 渲染卡片，打开弹窗才拉 CodeMirror。

快捷键：`Alt + N` 新建，`Ctrl/Cmd + F` 搜索；弹窗内 `Ctrl/Cmd + Enter` 保存，`Esc` 关闭（有未保存改动时会先确认）。

**数据存在 localStorage**，也就是当前浏览器里 —— 换设备、换浏览器看不到，清理站点数据会丢失。要跨设备访问得用「导出 / 导入」手动搬，或者改成服务端存储（见下）。

渲染 Markdown 时关闭了原始 HTML（`html: false`），并限制链接协议只允许 `http/https/mailto`，所以粘贴来的内容不会造成 XSS。

#### 改成服务端存储

存储逻辑集中在 `src/notes/lib/storage.ts` 的 `load` / `save` 两个函数里，换成 `fetch` 即可，上层组件不用动。但注意静态服务器只能读不能写，服务端存储需要一个能接收写入请求的进程（自建 Node、nginx 的 WebDAV 模块、或 Serverless 函数），并且**写接口必须加认证**，否则任何人都能读改你的便签。

## 技术栈

Vue 3 + Vite（多页面）、TypeScript、CodeMirror 6、jsondiffpatch、markdown-it。

每个工具独立打包。首屏加载量：首页 80 KB、便签集 198 KB、JSON 工具 511 KB。CodeMirror 被两个工具共享，抽成了公共块。

## 部署

`npm run build` 后把 `dist/` 整个目录交给任意静态服务器即可。资源引用是相对路径，放在域名根目录或子目录都不用改配置。

## 已知限制

- 便签数据只在当前浏览器（localStorage），不跨设备；配额约 5 MB，接近上限会提示导出
- 两列视图超过 20000 行会截断；变更清单不受影响，始终完整
- 两侧对象 key 顺序冲突时，两列按左侧顺序对齐（JSON 的 key 顺序不影响语义）
- 数组元素移动在两列里显示为「左删右增」，以保证每一列单独取出来仍是原本那份文档；变更清单里如实标为「移动」
